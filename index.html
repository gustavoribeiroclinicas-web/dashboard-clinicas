ℹ️ Como funciona a leitura dos profissionais

O sistema lê automaticamente o nome de cada profissional diretamente da planilha.

Psicóloga: tabela com 4 colunas — a 2ª coluna do cabeçalho deve ter o nome (ex: "Meriley").
Médica: tabela com 2 colunas — a 1ª coluna do cabeçalho deve ter o nome (ex: "Claudia").

Para adicionar uma substituta, basta criar uma nova tabela na aba da clínica seguindo o mesmo padrão. O sistema soma todos os atendimentos por profissional automaticamente.
